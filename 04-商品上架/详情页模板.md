# 商品详情页模板

## 使用方式

确定测试主题后，Trae根据以下模板生成完整的商品详情内容，存入 `04-商品上架/产出/[主题名]/`。

---

## 商品详情结构

### 一、商品标题（小红书商品标题，≤30字）

```
🎯 [测试主题核心卖点，如"1分钟测出你的隐藏性格"]
```

---

### 二、商品描述

```
【你会得到什么】
✅ 1套专属心理测试题（[X]道精选题目）
✅ 1份详细测试报告（[XX]字以上深度分析）
✅ 即时出结果，做完立刻看

【为什么选我】
🔮 题目精心设计，不敷衍
📊 结果报告详细，不是随便一句话
💰 [X.XX]元，一杯奶茶钱都不到

【怎么测】
1️⃣ 下单后自动发送测试链接
2️⃣ 手机点开就能测，不用下载
3️⃣ 1分钟出结果
```

---

### 三、详情图素材

需要准备2-3张图片：

**图1：测试封面预览**
- 展示测试页的封面截图或设计稿
- 标注"做完立刻看结果"

**图2：结果报告预览**
- 展示结果页的部分内容（打码/模糊处理，留悬念）
- 标注"详细分析，不止一句话"

**图3：使用指引**（可选）
- 简短的3步使用说明
- "下单 → 打开链接 → 看结果"

---

---

## 生成规范

1. 商品描述控制在300字以内，重点突出"能得到什么"
2. 详情图用纯文字排版即可（用HTML生成截图），不需要复杂设计
3. 不要虚假宣传（如"改变人生"），避免退款纠纷
4. 每个主题生成独立的商品详情，不要多个主题共用一个
