# 封面图AI生图提示词模板

## 使用方式

我将根据测试主题，基于以下模板生成具体的Seedream/可灵生图提示词。
你复制提示词到生图工具生成图片，保存到 `03-笔记素材/产出/[主题名]/` 目录。

---

## 提示词模板结构

每个封面图的提示词包含4个要素：

```
[风格基调] + [主体元素] + [文字区域] + [画面氛围]
```

---

## 风格方向（对调研完成后根据同行风格确定）

### 方向A：治愈插画风
```
风格：温暖治愈的扁平插画风格，柔和的渐变色背景
主体：[根据主题描述]
文字区域：画面中央偏上留有文字放置区域
氛围：温暖、舒适、让人想点击
```

### 方向B：神秘心理风
```
风格：深色背景搭配发光元素，神秘而有质感
主体：[根据主题描述]
文字区域：画面中央
氛围：神秘、好奇、探索感
```

### 方向C：清新手账风
```
风格：清新手账拼贴风格，浅色背景，手写字体装饰元素
主体：[根据主题描述]
文字区域：画面中央偏上
氛围：轻松、有趣、少女感
```

---

## 生成要求

1. 同一账号所有封面图使用同一风格方向，保持视觉统一
2. 每张图的颜色基调根据主题微调（性格=蓝色、爱情=粉色、职场=橙色、趣味=绿色）
3. 图中**不要**包含具体文字（文字由小红书编辑器叠加或我另外处理）
4. 尺寸提示：3:4竖版比例

---

文字区域：画面中央偏上，暗色半透明区域
