# Blueberry Studio 测试页竞品分析

> 分析对象：https://theblueberrystudio.com/life/ | 对应小红书笔记"你适合轨道人生还是旷野人生"（1013赞，其最高爆款）

---

## 一、页面结构拆解

### 封面页 (theblueberrystudio.com/life/)
```
标题：你适合 轨道人生还是旷野人生？
副标题：有些人适合把一条路慢慢走深，有些人适合在未知里长出新的自己。
引导语：5道题，看看你的内心更靠近哪一种人生节奏。
CTA按钮：[开始测试]
辅助信息：大约 1 分钟完成 · 单选题
```

### 测试页 (theblueberrystudio.com/life/test.html)
- 5道单选题，逐题展示
- 第1题内容：10年后的一天你会选择看什么？4个选项
- UI特征：顶部显示"第 X / 5 题  轨道 × 旷野"
- 按钮：「上一题」「下一题」

## 三、值得借鉴的点

### 1. 封面独立，URL分离
- 封面页 `/life/` 和测试页 `/life/test.html` 分开
- **好处**：封面页可以做SEO优化、社交分享预览
- **我们的改进方向**：可以考虑用单独的 index.html 做封面入口

### 2. "上一题"功能
- 允许用户回退修改答案
- **好处**：降低用户焦虑（怕选错），提升完测率
- **我们的改进方向**：加一个简单的"返回上一题"按钮

### 3. 5题 vs 8题
- 5题更短，用户完测率可能更高
- **决策**：保持8题不动——新手用户反馈少时先按照调研结论（行业普遍5-10题），后续根据完测率数据再调

### 4. 二选一结果格式
- 这次测试的结果是两种极端类型（轨道 vs 旷野），对应其账号"你更适合X还是Y"的选题句式
- **我们的结果设计**：4种类型（计分制），更丰富但也更复杂
- **判断**：两种各有适用场景。二选一适合话题型（测完发评论区讨论），四类型适合付费型（用户觉得值）

### 5. 干净的独立域名
- 不是 GitHub Pages 子域名
- **启示**：长期来看买个便宜域名（几十块/年）挂到 Pages 上，信任感更强

## 四、需要避开的坑

### 1. SPA导致抓取困难
Blueberry 的测试页是纯 JS 渲染，WebFetch 无法抓取完整题目。这意味着：
- 搜索引擎无法索引测试内容
- 微信/小红书的内嵌预览不可用
- **我们的模板是静态HTML**：题目内容直接写在 HTML 里，SEO友好，预览可用 ✅

### 2. 域名与账号不绑定
theblueberrystudio.com 主站是外籍人士服务公司，测试页面只是挂在上面的子页面，显得不够专业。
- **我们的策略**：用 GitHub Pages 的干净 URL，或买独立域名
